# Fast & Slow Pointers

Two pointers move through a sequence at different speeds (usually 1 and 2 steps), so they meet inside a cycle or the slow one lands on the middle.

## Spot it when
- Linked list: detect a cycle, find where it starts, find the middle, check palindrome, reorder.
- An array whose values are indices into itself (Find the Duplicate Number): treat `i → nums[i]` as a linked list.
- A sequence generated by a function that might loop (happy number).

## The idea
If there's a cycle, the fast pointer gains one step per move and must meet the slow one inside it (Floyd). To find the cycle's entry, reset one pointer to the head and move both one step at a time; they meet at the entry. With no cycle, when `fast` reaches the end, `slow` is at the middle.

## Java template
```java
ListNode slow = head, fast = head;
while (fast != null && fast.next != null) {
    slow = slow.next;
    fast = fast.next.next;
    if (slow == fast) {                      // cycle found
        ListNode p = head;
        while (p != slow) { p = p.next; slow = slow.next; }
        return p;                            // cycle start
    }
}
return null;                                 // no cycle; slow is the middle
```

## Complexity
O(n) time, O(1) space, which is the whole point versus a `HashSet` of visited nodes.

## Pitfalls
- Null checks: test `fast != null && fast.next != null` before stepping.
- For an even-length list, decide which middle you want (`fast = head.next` gives the first middle).
- Palindrome / reorder: find the middle, reverse the second half, compare or weave, then optionally restore.
